五分钟上手

安装、登录、点开第一个话题。教程到这里就结束了。

  1. 安装。打开 Releases 页。macOS 把 DMG 里的应用拖进「应用程序」；Windows 双击 MSI；Linux 用 deb / rpm / AppImage。
  2. 打开。启动即读：侧栏列出论坛最新话题，不需要账号。
  3. 登录（可选）。点「登录」。浏览器打开论坛授权页，点批准；把论坛显示的那串代码粘贴回应用。完成。
  4. 读第一个话题。点侧栏任意一行。整条讨论按阅读顺序排好，长帖也能一口气读完。

提示：登录只影响写操作——回帖、点赞、通知。只读不登录，一切照旧。

话题与阅读

  • 浏览最新。侧栏按分类列出最新话题；回复、浏览、点赞数一目了然。
  • 搜索归档。点搜索框，回车即搜。键盘直达。
  • 读长帖。读帖视图按阅读顺序呈现整条讨论；作者头像、原帖链接随手可点。
  • 离线重读。每次响应都落盘缓存。重开页面不重新请求。

登录与账号

登录用 Discourse 官方的 user API key 流程，Threadly 不碰你的论坛密码。

  1. 点「登录」。应用打开论坛授权页。
  2. 批准授权。申请的权限是 read | write | notifications——读、写、通知，仅此三项。
  3. 粘贴代码。论坛批准后显示一段加密文本；复制，粘进应用，确认。

密钥只存本机（0600 权限）。换机器要重新登录；登出即删。

通知

登录后，侧栏有「通知」。点开，看论坛的回复、提及与点赞。

  • 通知来自论坛本体，Threadly 只读不存。
  • 点一条通知，直接跳到对应话题。

点赞

  • 看点赞。每楼右侧显示论坛的点赞数——打开就有，不是空白。
  • 点赞。点红心即可。你点过的楼显示实心，论坛状态实时同步。

AI 摘要与翻译

摘要和翻译走你自己的 OpenAI 兼容端点。配一次，三平台都能用。默认未配置——不配置就没有 AI 功能，其余一切照常。

配置（一次）

终端里执行：

threadly ai-config --base-url https://api.example.com/v1 \
  --api-key sk-... --model gpt-4o-mini --target-lang zh
  • --base-url：聊天补全端点根地址（OpenAI 兼容即可）。
  • --api-key：该端点的密钥。只存本机 ai-config.json，权限 0600，只发往该端点。
  • --model：模型名，如 gpt-4o-mini。
  • --target-lang：翻译目标语言，如 zh、en。

不带参数执行 threadly ai-config 可查看当前配置。

使用

  • 摘要。打开话题，点「摘要」。长帖几十秒出要点。
  • 翻译。点「翻译」。整条讨论译成目标语言。
  • 命令行。threadly summary <id>、threadly translate <id> 同样可用。

更新

  • 自动检查。应用每 4 小时静默查一次新版；有新版才提醒。
  • 手动检查。macOS 在菜单 Threadly → Check for Updates；Windows/Linux 在应用内更新入口。命令行也可：threadly update-check。
  • 安装。确认后应用自己下载、验签、换新并重启。更新包带 Ed25519 签名，验证不过不安装。

常见问题

登录页让我批准哪些权限？

read | write | notifications。读话题、回帖点赞、收通知。没有更多。密钥随时可在论坛个人设置里吊销。

我的数据存在哪里？

平台数据目录
macOS~/Library/Caches/threadly
Linux~/.cache/threadly（或 $XDG_CACHE_HOME/threadly）
Windows%LOCALAPPDATA%\threadly

里面有：话题缓存、登录密钥（0600）、AI 配置（0600）、更新下载。删目录即重置。

必须注册账号吗？

不。匿名可读、可搜。登录只为回帖、点赞、通知。

支持哪些平台？

macOS 14+（Apple Silicon 与 Intel）、Windows 10+（x64）、Linux（x64 / arm64，GTK4）。移动端在路线图上。

怎么更新？

见上文「更新」。简版：应用内确认，一键完成；或到 Releases 页手动下载。

怎么卸载？

macOS 把应用拖进废纸篓；Windows 在「设置 → 应用」卸载，或另存便携 zip 直接删除；Linux 卸载对应的包。再删掉上文的数据目录，痕迹清零。
