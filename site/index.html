原生客户端 · 登录回帖 · AI 摘要与翻译

在浏览器之外，读 Racket 社区。

Racket 的设计讨论、提案与生态动态都发生在 racket.discourse.group—— 而浏览器给这些长技术帖套上了一层层外壳。Threadly 用匿名公开的 JSON API 把它们带回原生窗口：论坛原色分类、帖子头像、680px 的阅读栏宽。

为什么需要

🪟

浏览器不是阅读器

每页论坛都在加载一个 Web 应用——脚本、侧栏、层层 chrome。切个窗口，读了一半的长帖就找不到了。

📖

长帖配得上更好的排版

关于类型系统和宏展开器的讨论动辄上百楼：680px 阅读栏宽、帖子头像、论坛原色分类，长文终于有了阅读的样子。

🖥️

桌面端本来就没有

Discourse 只有官方 iOS/Android 应用，桌面用户拿到的只是一个网址。Threadly 补上这块，且与产品线一样全平台。

设计原则

论坛是唯一事实源

Threadly 只缓存、不分叉：编辑、删除、挪版永远以论坛为准，每个帖子都能一键跳回原链。

做好公民

只打公开端点，响应全部落盘缓存并带 TTL，请求带身份标识的 User-Agent，收到 429 老实退避。

凭据留在本机

匿名即可读；登录走 Discourse user API key 流，凭据只存本机——回帖、点赞、通知不经过任何第三方。

长文优先

阅读体验就是产品本身；要移除的恰恰是层层 chrome。Racket 引擎 + 第一方原生 UI，没有 WebView 套壳的网页应用。

三步开始

1

下载安装

macOS 拖进应用程序文件夹即可——不注册也能读，没有遥测。

2

浏览最新

侧栏按分类原色列出论坛最新主题，回复、浏览与点赞一目了然；所有响应落盘缓存，重复打开不重复请求。

3

搜索归档，读长帖

键盘直达全站搜索；读帖视图按阅读顺序呈现整条讨论，随时一键跳回网页原帖。
